# toy-llm：用纯 C 从零写一个迷你 GPT

> 写于 2026 年 10 月。
> 这个项目是AI指导我一步步自己写的，代码全部我手敲。
> 这份 README 主要写给未来回来看的自己。

## 它是什么

- **约 310 行纯 C**，只用了 stdio.h 和 math.h
- 一个**会自己训练的迷你 GPT**：
  - 推理：查表 → 位置编码 → 单头因果注意力 → 输出层 → a/b 概率
  - 训练：**数值梯度下降**（中心差分逐个测梯度），loss **0.678 → 0.0002**
- 训练完自动接龙：种子 "a" 写出 `abababab`；换 "b"/"bb" 照样交替——它学的是"交替"这条**规则**，不是那 7 条样本

## 编译运行

    gcc -Wall main.c && ./a.exe

跑一次 = 训练 100 步（每步一行 loss）+ 接龙输出：

    step0: loss = 0.6707
    step99: loss = 0.0002
    ab / aba / abab / ... / abababab

改数据集：data[] 和 answer[]（当前语料 abababab 切成 7 道题；N=7 要跟着题数改）。
调学习率：main 里的 lr（旁边注释有实验数据）。

## 流水线

**前向（forward()）**，从上往下读就是顺序：

    字符串 → 查表 → +位置 → ×wQ/wK/wV → 打分 Q·K/√d → 因果掩码 → softmax → 加权混合V → ×wOut → softmax → 概率

**训练（main()）**，每个 step 两遍走：

    先测：39 个权重逐个中心差分（拧+ε测一次、拧−ε测一次、拧回去），存进 g 数组
    后拧：全部权重统一 -= lr × g
    （必须先测完再统一拧——边测边拧，后面的测量用的就是过期地图）

## 实验记录

1. **loss 阶梯走完**：0.693 硬币 > 0.683 背词频 > 0.678 手填权重 → **0.0002 训练完**（每题押对概率 ≈ 0.9998）
2. **训练自愈复读机**：v1.0 手填权重贪心解码 → aaaaaa；训练完同一颗种子 → abababab
3. **灵敏度表**（39 个梯度的绝对值）：wQ/wK 基本摸鱼，Embedding/wV/wOut 在搬信号——"输入失明"的梯度版确诊
4. **lr 三档**：1.0 甜点；10 暴毙（第一步更甜 0.6437，第三步 -1.#IND）；0.1 过阻尼（100 步才 0.47）。判据：抛物线碗每步把离谷底距离乘上 (1 − lr×陡度)，绝对值大于 2 就发散
5. **泛化探针**：种子 "b" → babababa，"bb" → bbababab。训练集全是 a 开头、从无 bb 连排——照样交替；且自回归只往后写不回头改历史，bb 就错着接下去
6. **0.0002 是尺子的地板，不是模型的极限**：ε=0.01 的中心差分量不出更小的梯度——这就是反向传播的存在理由

## 踩坑记录（都是真的踩过）

1. `'0' ≠ '\0'`——字符零和空字符
2. **未初始化的 float sum** 里有残值
3. **数组传参传地址**——后来反向利用它写了 `gradient(float *w)`，隔地址拧单个权重
4. **dot(a,b,n) 的 n 传错**成位置，越界读不报错
5. **变量遮蔽**：循环内重新 int，改的是复印件
6. `total = +loss`——一元正号，安静给错数
7. **float 函数里 `return 1` 会伪装成真 loss**——错误信号用 -1.0f（loss 恒 ≥ 0，负数装不成读数）
8. **复制循环只改一半**：`for(int n...) i++`，编译器当场抓
9. **函数要先定义再调用**（或提前原型声明）
10. **测量和更新拆成两个大循环** = 拍一张照闭眼走 100 步，loss 不收敛——必须嵌套进每个 step：先测完 39 个，再统一拧
11. **手动同步对**：种子和 length、N 和 data[]——C 不替你数数
12. **-1.#IND / nan = NaN，数值死亡**，不是负 loss：链路 log(0) → ∞ → NaN 传染全模型
