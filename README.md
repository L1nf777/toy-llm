# toy-llm：用纯 C 从零写一个迷你 GPT

> 写于 2026 年 10 月。
> 这个项目是AI指导我一步步自己写的。
> 这份 README 主要写给未来回来看的自己。

## 它是什么

- **约 220 行纯 C**，只用了 stdio.h 和 math.h，没有别的库
- 一个**完整的 GPT 推理骨架**：读完 "abba" 这样的序列，然后一个字母一个字母地自动往下写
- 所有参数（Embedding、wQ/wK/wV、wOut）都是**手填的，还没训练**——所以它写得不聪明，但每个零件都是真的在转
- 2026-10-30：**训练开工**——数据集 + cross-entropy 损失就位，7 条样本平均 loss = 0.678（发动机"梯度"还没造）

## 编译运行

    gcc -Wall main.c && ./a.exe

改数据集：顶部的 data[] 和 answer[]（语料是 abababab，只认 a/b，单条最长 8 个）。
接龙生成代码注释休眠在 main() 末尾，等训练完唤醒做前后对比。

## 流水线

    "abba"
      │ 查表            字符 → 编号 → 查 Embedding 表 → 向量
      │ + 位置编码       每个位置叠加不同的位置向量
      │ × wQ/wK/wV      同一个 x 过三个矩阵
      │ 打分 Q·K/√d_k   每个位置给所有位置算相关度
      │ 因果掩码         j > i 的格子填 -1e9，不许看未来
      │ softmax          每行变成和为 1 的注意力权重
      │ 加权混合 V       out[t] = Σ 权重×V（本质是一次向量×矩阵）
      │ × wOut           最后一行变成 a/b 两个得分
      │ loss             -ln(给正确答案的概率)，7 条样本取平均
      │ 贪心 + 拼接      挑概率高的字母接回输入，循环（休眠中，见上）
      └──────▶ 模型自己往下写

## 踩坑记录（都是真的踩过）

1. **'0' ≠ '\\0'**——字符零和空字符，差一个反斜杠，循环冲出字符串读内存垃圾
2. **未初始化的 float sum;**——里面是上一个函数留在栈上的残值。
3. **数组传参是传地址**——函数里改数组影响外面（出参），标量只能靠 return
4. **dot(a, b, n) 的 n 是"这排数有几个"**——打分时把 length 传错成位置，越界读还不报错
5. **变量遮蔽（shadowing）**——循环内重新 int length，改的是复印件，死循环
6. **VLA**：float s[length][length] 合法，但 length 为 0 或 -1 是未定义行为
7. **softmax 溢出防御**（知道了但没做）：先减最大值再 exp
8. **total = +loss ≠ total += loss**——那个 + 是一元正号（就像 -5 里的负号），整行变成"每圈只保留最新值"：编译不报错、运行不崩溃、安静给错数。教训：loss 好得难以置信时，先怀疑 bug

## 实验记录（比代码更有意思）

1. **wQ = wK 时注意力方阵对称**——"我关注你 = 你关注我"
2. **未训练网络是"输入失明"的**：换输入，预测概率纹丝不动——随机权重下输出约等于常数
3. **手工注入知识**：把 a、b 的 Embedding 改成互为相反向量，模型立刻改口、概率开始随输入微动——相当于用手填扮演了训练
4. **固定偏置**：不管输入什么都偏向 b——logits ≈ 偏置 + 微弱信号，训练的本质是让信号压过偏置
5. **复读机**：贪心解码 + 注意力太软 → aaaaaa，和真实大模型的复读病同款
6. **损失阶梯**：0.693（五五开的硬币）> 0.683（只背频率的瞎子）> 0.678（本模型）——手填权重碰巧偏向 b，与数据集多数派 b:a = 4:3 同向，白赚 0.015。训练的第一步永远是背词频，真实大模型 loss 曲线开头的猛降就是它在背词频
